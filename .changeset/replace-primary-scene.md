The primary Daz scene card has a **browse-to-replace** button (folder icon) now: pick a new `.duf`, pass the same validation and copy-vs-link decision as Add scene, and it replaces the primary — the Genitalia section re-derives from the new scene's geograft, the avatar follows, and the old scene's files can be deleted in the same dialog when they were an in-folder copy (a linked-in-place original is always kept).
